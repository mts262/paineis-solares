# Monitoramento de Painéis Solares

Projeto acadêmico desenvolvido na disciplina de **Complexidade de Algoritmos**, no 5º semestre do curso de Bacharelado em Sistemas de Informação do IFBA.

## Sobre o projeto

O projeto consiste em uma simulação de monitoramento de painéis solares por meio da geração de leituras de sensores, como tensão, corrente elétrica, potência e temperatura.

A partir dos dados simulados, são implementadas operações para organizar, exibir e comparar as leituras dos painéis solares, permitindo estudar o comportamento de diferentes algoritmos e analisar suas complexidades.

## Objetivos

- Simular a geração de dados de sensores para múltiplos painéis solares.
- Implementar algoritmos para ordenação e processamento das leituras.
- Analisar a complexidade das operações implementadas.
- Observar como o desempenho dos algoritmos varia conforme o volume de dados processados.

## Tecnologias utilizadas

- Java
